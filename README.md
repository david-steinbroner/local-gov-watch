# Local Gov Watch

Follow the local decisions that affect where you live.

Local Gov Watch brings government meetings and public records into one place. The goal is to make it easier to find an agenda, understand what's being discussed, and follow an issue across nearby communities.

It's for residents, community groups, and anyone who would rather spend less time searching separate government websites.

[Visit Local Gov Watch](https://localgovwatch.com)

## What to explore

- Find meetings and the documents connected to them.
- Browse records from the communities covered by the project.
- Follow a topic back to its original public source.

Coverage and available records depend on each government's publishing systems. This is an evolving project, not a complete record of every local decision.

## Work on the project

Start with [the project guide](CLAUDE.md). [North Bay setup](NORTH_BAY_SETUP.md) and [data collection notes](CONNECTOR_RERUN_INSTRUCTIONS.md) explain how coverage is configured.

```bash
npm install
npm run dev
```

The app uses Supabase for its data. Use your own development settings when working locally.
